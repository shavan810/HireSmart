My project is called HireSmart, an AI-powered job portal developed using the MERN stack.

The main purpose of this project is to connect job seekers and recruiters on a single platform.

It has three roles: Job Seeker, Recruiter, and Admin.

Job seekers can search and apply for jobs, upload resumes, and track their applications. Recruiters can post jobs and manage applicants, while admins manage the overall platform.

One of the key features is AI Resume Analysis, where I integrated Google Gemini API to analyze resumes and provide feedback.

I also used JWT for authentication, Cloudinary for file storage, and Socket.io for real-time notifications.

Through this project, I gained practical experience in full-stack development, REST APIs, authentication, and third-party API integration.
